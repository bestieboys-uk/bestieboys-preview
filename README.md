# BestieBoys Development Preview

Public visual preview of the BestieBoys storefront.

- Development build
- Not for sale
- No checkout or payment
- Private, password-protected Tally Phase B intake is available for controlled upload testing
- No submission creates an order or sends anything to production
- Internal project documents are intentionally excluded
- Production storefront remains private

## Onion Black Metal visual mockups

The Black Metal product review uses three derived 1600×2000 WebP garment mockups:

- `review-v3/assets/mockups/onion-black-metal/bm-01-front.webp`
- `review-v3/assets/mockups/onion-black-metal/bm-02-front.webp`
- `review-v3/assets/mockups/onion-black-metal/bm-03-front.webp`

Each mockup is deterministically composited from its approved Onion source artwork. The approved JPEG masters and the nine-scene locked sprite remain unchanged. The washed-black garment is a non-supplier-specific visual base, so these images are placement studies rather than print proofs or claims about a final blank.
