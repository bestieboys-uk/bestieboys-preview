# BestieBoys Development Preview

Public visual preview of the BestieBoys storefront.

- Development build
- Not for sale
- No checkout or payment
- Private, password-protected Tally Phase B intake is available for controlled upload testing
- No submission creates an order or sends anything to production
- Internal project documents are intentionally excluded
- Production storefront remains private

## Onion scene product reviews

All nine Onion genres expose their three approved directions through the review storefront. Black Metal retains its compatibility page; the other eight use the shared `review-v3/onion-product.html?scene=…` template and catalog.

Each direction has a derived 1600×2000 WebP T-shirt placement study. The washed-black garment is a non-supplier-specific visual base, so these images are not production mockups, print proofs, or claims about a final blank.

The exact locked 1260×3780 binary WebP remains authoritative for all 27 selections. Recovered standalone sources are retained byte-for-byte for sharper display; the nine selections without a surviving standalone file remain rendered directly from their approved sprite cells. Old inline-base64 SVG garment wrappers were removed.
